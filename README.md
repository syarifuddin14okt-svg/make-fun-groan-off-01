## The joke

> I asked my dad why he keeps a pencil behind his ear. He said, 'In case I need to draw the line somewhere.'

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`, asserting the competition gate first: one line, 1–140 characters, not whitespace-only.

```sh
python3 main.py
cat /output/entry.txt
```
